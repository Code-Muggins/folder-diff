# folder-diff · 纯本地文件夹差异对比工具

左右分栏对比两个文件夹的 Web 工具。**没有后端、不发任何网络请求**，双击 `index.html` 就能用，文件数据全程留在浏览器里。

## 快速开始

双击 `index.html`（或把它拖进浏览器）。不需要安装依赖、不需要启动服务器、不需要联网。

也可以起个本地服务（某些浏览器的拖拽行为会更稳定）：

```bash
cd folder-diff
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```

## 界面结构

- **左右两栏**：A / B 各自导入文件夹，以相对路径的树形结构展示，支持展开 / 折叠
- **底部抽屉**：点击文件后展示内容或差异
- **工具栏**：同步联动、同步滚动、忽略规则、搜索过滤、差异统计、进度条

## 用法

1. 两侧分别「选择文件夹」，或直接把文件夹拖进对应面板（会递归包含子目录）
2. 导入完成后自动比对，差异项按状态着色：
   - **红色**：两边都有但内容不同
   - **橙色**：仅 A 有
   - **玫红**：仅 B 有
   - **灰色**：两边相同
3. 点击任意文件查看内容 / 差异，用 `↑ 上一个` `↓ 下一个` 在差异文件间跳转

### 差异判定规则

按**相对路径 + 文件名**建立两侧配对（会自动剥掉最外层目录名，所以 `A代码/` 与 `B代码副本/` 也能正确配对），然后：

1. 先比文件大小，**大小不同直接判定内容不同**（不必读取文件内容，大目录提速的关键）
2. 大小相同才按 1 MiB 分片流式计算 SHA-256
3. 超过「单文件哈希上限」（默认 20 MB）的文件不读内容，保守判定为相同，并在文件名后标记 `≈`

目录的状态由子项自底向上汇总，所以折叠状态下也能看出哪个目录有问题。

### 同步联动与同步滚动

- **同步联动**（默认开）：点击一侧的共有文件，另一侧同步选中并定位，底部展示双栏 diff
- **同步滚动**（默认开）：两侧目录树一起滚动。两侧行数不同时（存在仅单侧的文件），按**顶部行的路径**做锚点对齐，而不是按像素硬对齐，不会越滚越错位

两个开关互相独立，可以只开滚动、不开联动。

### docx 文档式对比

docx 本质是 ZIP 容器，工具会解压出 `word/document.xml` 的段落文本再做对比，有两种视图：

- **文档视图**（默认）：段落按文档排版流式渲染（衬线字体、两端对齐、自动换行），改动的段落做**字符级 diff**，只把真正不同的字标出来——删除用红色删除线，新增用绿色下划线
- **逐行视图**：切回传统的代码式行 diff（带行号）
- 并排视图对应双栏对齐，统一视图对应 **Redline 单栏**（删除与新增内联混排在同一段里）

> 注意：看到的是提取出的纯文本，不是原始排版（字体、字号、图片、表格样式都不保留）。
> 超过 50 MB 的 docx 不解压，会回退到元信息展示。xlsx / pptx 目前仍只显示元信息。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构，工具入口 |
| `styles.css` | 样式（深色主题） |
| `core.js` | 纯逻辑层：SHA-256、忽略规则、目录树、差异模型、LCS diff、ZIP / docx 解析。无 DOM 依赖，可在 Node 下单测 |
| `app.js` | 交互层：导入、异步比对与进度、虚拟滚动渲染、联动、diff 预览 |
| `test/core.test.js` | core.js 单元测试 |
| `test/smoke-test.js` | 浏览器端冒烟用例 |
| `test/make-smoke.py` | 由 `index.html` 生成 `test/smoke.html`（改完 index.html 需重新生成） |
| `test/cdp-smoke.js` | 无头浏览器驱动脚本（CDP over WebSocket） |

## 性能与限制

- 忽略规则默认跳过 `node_modules`、`.git`、`.DS_Store` 等，可在「忽略规则 / 性能」里编辑
- 文件总数、哈希体积上限、预览体积上限都可配置；比对过程异步分片执行，带进度条且可取消
- 大目录建议先用忽略规则缩小范围

## 实现上的几个取舍

- **不用 `crypto.subtle`**：它只在安全上下文可用，为了 `file://` 双击可用，自己实现了纯 JS 的流式 SHA-256
- **不用 ES Module**：`file://` 下会被 CORS 拦截，改用传统 `<script>` 分文件
- **零第三方依赖**：ZIP 解压用浏览器内置的 `DecompressionStream('deflate-raw')`

## 测试

```bash
# 纯逻辑单测（Node 18+）
node test/core.test.js

# 浏览器端冒烟（自动拉起无头 Edge）
python3 test/make-smoke.py
node test/cdp-smoke.js "file:///绝对路径/test/smoke.html"
```

## 隐私

所有比对都在浏览器本地完成，文件不会被上传、不会被写入磁盘、页面也不发起任何外部请求。
